# LinguaQ AI
AI-Powered Multilingual Question-Answer Generation System.

Features:
- PDF, DOCX and TXT input
- English, Hindi and Marathi Q&A
- Light/Dark mode compatible interface
- Generation settings
- Progress tracking
- Language count validation
- Excel export with Summary, English, Hindi and Marathi sheets

Run:
```bash
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
